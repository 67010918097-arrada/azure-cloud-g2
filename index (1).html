Azure คืออะไร

Microsoft Azure คือแพลตฟอร์มคลาวด์ของ Microsoft ที่ให้เช่าทรัพยากรไอที เช่น เซิร์ฟเวอร์ ฐานข้อมูล เครือข่าย และ AI ผ่านอินเทอร์เน็ต แทนการซื้อและดูแลฮาร์ดแวร์เอง

Cloud Computing

การใช้ทรัพยากรคอมพิวเตอร์ตามต้องการผ่านเครือข่าย จ่ายตามการใช้งาน

บทบาทของ Azure

เป็น Public Cloud ที่ให้บริการแบบ IaaS, PaaS และ Serverless รวมถึงเครื่องมือด้านข้อมูลและ AI

ใครใช้ได้

นักพัฒนา องค์กร หน่วยงานรัฐ และนักศึกษา ตั้งแต่เว็บแอปขนาดเล็กถึงระบบองค์กร

2.1 Azure Services

แตะการ์ดเพื่อดูรายละเอียด แต่ละบริการระบุ Azure Product ที่ใช้เป็นตัวอย่าง

2.2 Data Center Location

Region คือกลุ่ม Data Center ในพื้นที่หนึ่ง Availability Zone คือตำแหน่งแยกทางกายภาพภายใน Region เพื่อความทนทาน บาง Region มี Region Pair สำหรับ Disaster Recovery

แตะหมุดบนแผนที่เพื่อดูข้อมูล Region

ตรวจสอบ ณ ปี 2026: Microsoft ประกาศแผนสร้าง Azure Region ในประเทศไทย (ลงทุนกว่า 1 พันล้านดอลลาร์สหรัฐ ช่วง 2026–2028) แต่ยังเป็นแผน ไม่ใช่ Region ที่เปิดให้บริการ

2.4 Strengths & Considerations

Strengths

  • โครงสร้างพื้นฐานระดับโลกที่มี Region จำนวนมาก
  • พอร์ตโฟลิโอบริการกว้าง ตั้งแต่ IaaS ถึง AI
  • เชื่อมต่อกับระบบองค์กร Microsoft และ Entra ID
  • มีเครื่องมือด้านความปลอดภัยและนักพัฒนา

Considerations

  • โครงสร้างราคาซับซ้อน ต้องวางแผนและติดตามค่าใช้จ่าย
  • มี Learning Curve จากจำนวนบริการ
  • ควรพิจารณาความเสี่ยง Vendor Lock-in
  • บริการบางรายการไม่มีในทุก Region
